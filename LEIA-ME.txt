FUT DE SEXTA — PROTÓTIPO PARA PREPARAÇÃO

Arquivos:
- index.html: página inicial com links para as duas áreas.
- organizador.html: painel do organizador, com tela de código de demonstração.
- jogador.html: página para confirmação de presença e lista de espera.

Como testar:
1. Extraia o ZIP para uma pasta.
2. Abra index.html no navegador.
3. Entre na área do organizador e use o código temporário 2468.
4. Abra a área do jogador para testar a interface.

IMPORTANTE:
Este é apenas um protótipo local. Os dados ficam no armazenamento do navegador e não são sincronizados entre dispositivos. O código 2468 é demonstrativo e NÃO é segurança real, pois está no código da página. Não use para proteger informações reais. Antes de publicar, é necessário configurar autenticação validada no servidor e banco de dados compartilhado, além de revisar as permissões do organizador.
